# scikit-learn Cookbook

This repository contains chapter-by-chapter code reproduction, summaries, and theoretical explanations based on the book **scikit-learn Cookbook (Third Edition)** by John Sukup.

## 📘 Objective

To improve practical Machine Learning skills using Python and scikit-learn through structured implementation of models, preprocessing techniques, evaluation methods, and deployment workflows.

## 📚 Chapter Descriptions

### Chapter 01 - API Basics

Introduces the fundamental scikit-learn workflow including datasets, estimators, transformers, pipelines, model training, prediction, and evaluation.

### Chapter 02 - Data Preprocessing

Covers essential preprocessing techniques such as handling missing values, feature scaling, imputation, and building preprocessing pipelines.

### Chapter 03 - Dimensionality Reduction

Explains Principal Component Analysis (PCA) and feature reduction methods to simplify datasets while preserving useful information.

### Chapter 04 - KNN

Focuses on K-Nearest Neighbors classification, distance metrics, feature scaling, hyperparameter tuning, and decision boundaries.

### Chapter 05 - Linear Models

Discusses Linear Regression, Ridge, and Lasso models for numeric prediction, including regularization and coefficient interpretation.

### Chapter 06 - Logistic Regression

Introduces Logistic Regression for classification tasks, probability prediction, ROC curves, thresholding, and model interpretation.

### Chapter 07 - SVM

Explains Support Vector Machines, margin maximization, kernel methods, linear vs non-linear classification, and parameter tuning.

### Chapter 08 - Tree Ensemble

Covers Decision Trees, Random Forest, ensemble learning, feature importance, and overfitting control through tree depth.

### Chapter 09 - Text Processing

Demonstrates text preprocessing using Bag of Words, TF-IDF, and multiclass document classification using machine learning.

### Chapter 10 - Clustering

Introduces unsupervised learning methods such as KMeans and DBSCAN, including cluster evaluation and visualization.

### Chapter 11 - Outlier Detection

Explores anomaly detection techniques such as Isolation Forest and Local Outlier Factor for identifying unusual observations.

### Chapter 12 - Cross Validation

Focuses on reliable model evaluation using train/test split, k-fold cross-validation, validation curves, and learning curves.

### Chapter 13 - Deployment

Demonstrates how trained models are saved, loaded, and used in production environments for real-world predictions.
